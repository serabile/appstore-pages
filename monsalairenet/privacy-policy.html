Politique de Confidentialité

Application Mon Salaire Net

Important : Mon Salaire Net respecte votre vie privée. Aucune donnée personnelle identifiable (nom, email, coordonnées) n'est collectée par cette application.

1. Introduction

Cette politique de confidentialité décrit comment l'application "Mon Salaire Net" collecte, utilise et protège les informations lors de votre utilisation de l'application. Nous nous engageons à protéger votre vie privée et à être transparents sur nos pratiques.

2. Informations Collectées

2.1 Données Personnelles

Mon Salaire Net ne collecte AUCUNE donnée personnelle identifiable. Nous ne collectons pas :

  • Nom ou prénom
  • Adresse email
  • Numéro de téléphone
  • Adresse postale
  • Informations de compte bancaire
  • Toute autre information permettant de vous identifier personnellement

2.2 Données de Calcul

Les montants de salaire que vous saisissez pour effectuer vos calculs sont traités localement sur votre appareil et ne sont jamais transmis à nos serveurs ou à des tiers. Ces données restent privées et sous votre contrôle.

2.3 Données Techniques et Analytiques

Pour améliorer la qualité et la stabilité de l'application, nous utilisons Firebase Crashlytics et Firebase Analytics. Ces services collectent des informations techniques anonymes telles que :

  • Modèle de l'appareil
  • Version du système d'exploitation
  • Version de l'application
  • Données de diagnostic en cas de plantage
  • Statistiques d'utilisation anonymes (pages consultées, fonctionnalités utilisées)

Ces données sont collectées de manière anonyme et ne permettent pas de vous identifier personnellement.

3. Utilisation de l'API URSSAF

Mon Salaire Net utilise l'API publique de l'URSSAF pour effectuer les calculs de cotisations sociales et de salaire net. Cette API est utilisée pour :

  • Obtenir les taux de cotisations à jour
  • Calculer les montants de cotisations sociales
  • Convertir le salaire brut en salaire net

Les requêtes envoyées à l'API URSSAF ne contiennent aucune information personnelle vous concernant. Seules des données de calcul anonymes (montants, taux applicables) sont échangées.

4. Utilisation des Données

Les données techniques collectées via Firebase sont utilisées uniquement pour :

  • Détecter et corriger les bugs et plantages de l'application
  • Comprendre comment l'application est utilisée afin d'améliorer l'expérience utilisateur
  • Optimiser les performances de l'application

5. Partage des Données

Nous ne vendons, ne louons et ne partageons aucune donnée personnelle avec des tiers à des fins commerciales. Les seules données partagées sont les données techniques anonymes collectées par Firebase, qui sont hébergées sur les serveurs de Google conformément à leur politique de confidentialité.

6. Sécurité des Données

Nous prenons la sécurité au sérieux. Les données de calcul restent locales sur votre appareil. Les données techniques collectées sont transmises de manière sécurisée via des connexions HTTPS chiffrées.

7. Services Tiers

Cette application utilise les services tiers suivants :

  • Firebase Crashlytics et Analytics (Google) : Pour le suivi technique et l'amélioration de l'application. Politique de confidentialité Firebase
  • API URSSAF : Pour les calculs de cotisations sociales. Politique de confidentialité URSSAF

8. Vos Droits

Étant donné que nous ne collectons aucune donnée personnelle identifiable, il n'y a pas de données personnelles à consulter, modifier ou supprimer. Vous gardez le contrôle total sur les données de calcul qui restent sur votre appareil.

9. Modifications de cette Politique

Nous pouvons mettre à jour cette politique de confidentialité occasionnellement. En cas de changements significatifs, nous vous en informerons via une notification dans l'application ou une mise à jour de cette page. Nous vous encourageons à consulter régulièrement cette politique.

10. Contact

Si vous avez des questions concernant cette politique de confidentialité ou l'utilisation de vos données, vous pouvez nous contacter par email : serabile@gmail.com
