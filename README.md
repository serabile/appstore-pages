# appstore-pages
For apps stores pages

## Structure

This repository hosts web pages for app store configurations, including privacy policies and other required pages.

### Mon Salaire Net

Privacy policy pages for the Mon Salaire Net application (French salary calculator):

- **French version**: [monsalairenet/privacy-policy.html](monsalairenet/privacy-policy.html)
- **English version**: [monsalairenet/privacy-policy-en.html](monsalairenet/privacy-policy-en.html)

#### Privacy Policy URL for Google Play Console

Use this URL in your Google Play Console configuration:
```
https://serabile.github.io/appstore-pages/monsalairenet/privacy-policy.html
```

#### Key Points

The privacy policy states that:
- No personally identifiable data (name, email, contact information) is collected
- The app uses the URSSAF API for salary calculations
- Firebase Crashlytics and Analytics are used for technical tracking
- All salary calculation data remains local on the user's device
